# 필드마크 (Field Mark) — 모바일 현장 기록 MVP

사진 위에 **직접 측정한 치수**와 **현장 메모**를 기록하고, 이미지 또는 PDF 인쇄용 보고서로 출력하는 오프라인 우선 앱입니다. 이 저장소는 **실제로 작동하는 모바일 웹/PWA MVP**입니다. 아직 App Store/Google Play에 등록된 네이티브 앱은 아닙니다.

## 실행

Node.js가 있으면 외부 의존성 설치 없이:

```bash
npm run dev
```

또는 `python3 -m http.server 5173`. 브라우저에서 `http://127.0.0.1:5173`에 접속합니다. 휴대폰에서 사용하려면 HTTPS로 호스팅해야 서비스워커와 사진 저장 등 PWA 기능을 안정적으로 이용할 수 있습니다.

## 현재 구현된 기능

- 프로젝트 생성·이름 변경·삭제, 현장 위치/설명 기록
- 카메라 또는 갤러리 사진 여러 장 불러오기, 브라우저에서 크기 최적화
- 사진 위 드래그로 치수선 또는 L자형 가로·세로 동시 치수선 생성, mm·cm·m 단위 및 색상 지정
- 사진 위 터치로 메모 생성, 생성한 치수·메모 수정/삭제, 최대 30단계 되돌리기
- 이미지 PNG 저장/기기 공유, A4 보고서 인쇄(브라우저 인쇄 기능에서 PDF로 저장)
- 자동 저장(IndexedDB), 백업 JSON 내보내기/가져오기, 오프라인 앱 셸
- 외부 서버로 사진 전송하지 않음. 계정 및 네트워크 연결 불필요

## 확인할 사항 및 제한

- **자동 길이 측정이 아닙니다.** 실측값은 사용자가 입력합니다. 카메라나 사진의 픽셀로 실제 길이를 추정하지 않습니다.
- 브라우저에서 PDF를 **직접 생성하여 내려받는 것**이 아니라, 인쇄 메뉴에서 PDF 저장하는 방식입니다. iOS/Android의 브라우저별 인쇄 흐름은 별도 검증이 필요합니다.
- 사진·프로젝트는 해당 브라우저의 IndexedDB에 저장되므로 브라우저 데이터 삭제, 기기 교체, 저장공간 회수 시 사라질 수 있습니다. 중요한 기록은 **백업 저장**을 사용하세요.
- 백업에는 사진 데이터가 들어 있어 크기가 클 수 있습니다. 최대 75MB의 백업을 불러옵니다.
- 서명/날짜/담당자/점검 서식/팀 공동 작업/정확한 AR 측정/블루투스 거리측정기 연동은 아직 없습니다.
- 실제 인앱 결제와 무료 기능 제한은 구현하지 않았습니다. 사용성 검증 후 결제 시스템을 연결합니다.
- PNG 공유 및 인쇄 메뉴는 브라우저·기기 지원 여부에 따라 동작이 다를 수 있습니다.

## 앱스토어 출시 로드맵

1. **현장 사용성 검증:** Android Chrome, iPhone Safari, iPad Safari에서 실제 사진을 넣고 편집·백업·PDF 흐름을 점검합니다.
2. **네이티브 래핑:** Capacitor로 iOS/Android 프로젝트를 생성하고 카메라, 파일 저장·공유, 사진 접근 등 네이티브 흐름을 연결합니다. 개발·서명에는 Apple Developer, Google Play Console 계정이 필요합니다.
3. **유료 전환:** 한 개의 앱으로 출시하고 무료 기본 기능 + 일회성 Pro 잠금 해제(IAP)를 연결합니다. 결제 복원과 플랫폼별 샌드박스 테스트가 필수입니다.
4. **정책·품질 검토:** 개인정보처리방침, 고객지원, 앱스토어 스크린샷, 접근성, 로컬 저장·백업 UX, 다양한 크기의 사진, 저사양 기기 메모리 테스트를 완료합니다.
5. **베타 테스트와 출시:** TestFlight 및 Play 비공개 테스트, 스토어 심사를 거칩니다.

## 테스트

```bash
npm test
```

별도 라이브러리 없이 이미지 좌표 정규화·치수 유효성·선 선택에 사용하는 기본 계산을 검증합니다.

선택 사항: `playwright`를 설치하고 서버를 켠 상태에서 `node tests/browser-smoke.mjs`로 사진 추가·치수 입력·백업·재접속·보고서 생성 과정을 자동 검증할 수 있습니다. 현재 제작 환경의 Chromium 실행 제한으로 이 통합 테스트는 **아직 통과를 확인하지 못했습니다**.

## 구조

```text
index.html           화면/대화상자/인쇄 레이아웃
styles.css           모바일 반응형 디자인
app.js               프로젝트 편집, 이미지 입출력, 백업, 인쇄
storage.js           IndexedDB 로컬 데이터 저장
geometry.js          비율 보정, 좌표 변환, 히트 테스트
sw.js                오프라인 앱 리소스 캐시
manifest.webmanifest PWA 설치 메타데이터
icons/icon.svg       가칭 앱 아이콘
PRODUCT_SPEC.md      제품 전략/수익모델/향후 요구사항
```

이름 **필드마크**는 가칭이며 정식 출시 전 상표·동일 앱명 확인이 필요합니다.
